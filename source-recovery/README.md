# Historical source recovery

These source-only snapshots preserve previously unsubmitted intermediate implementations and regression definitions. They are not installed runtime modules or a replacement for current canonical source.

Several snapshots describe successive versions of the same module. Preserve current fixes and the complete current PRD when extracting any still-applicable increment. Do not bulk-copy a stage into the application. Relative imports in a snapshot may depend on its original source graph; this directory is not a standalone executable test suite.

No historical test pass is inherited by current main. Current integrated validation, dependency/pin reconciliation and review remain required. This directory contains no deployment configuration, credentials, raw acceptance logs or private operational handoff.
