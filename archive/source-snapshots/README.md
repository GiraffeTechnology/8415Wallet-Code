# Historical source snapshots

This directory preserves previously unpublished product-source variants for review. It is not an active implementation, a release candidate or a replacement for the canonical PRD and current runtime.

Each original source path is retained under a content-identified variant. The `.source` suffix prevents ordinary compiler and test discovery from treating disconnected historical fragments as an integrated application. Relative imports may require their original source graph. Do not execute these fragments or infer deployment, test, security or chain acceptance from their presence.

The manifest records the original source blob and any privacy neutralization. Account and tenant examples are synthetic; environment-specific execution comments and provider-policy examples are neutralized. No credentials, operational handoffs or original acceptance logs are included.

Current source files, source policy, package scripts, workflows, canonical requirements and active runtime paths are unchanged. Any selected integration must be reviewed separately against the complete current requirements, retain effective safeguards, and receive exact-source validation in the approved environment.
